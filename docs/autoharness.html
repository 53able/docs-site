Claude Code plugin / skill lifecycle

AutoHarness

Claude Code の作業セッションから再利用できるスキルを見つけ、検証して保存するプラグイン。重複を統合し、使われなくなったスキルはアーカイブします。

Python 3.11+Linux / macOS第三者依存なし

01 / 何を管理するか

AutoHarness は、Claude Code が使うネイティブな SKILL.md のうち、自身が作ったものを管理します。

作業から学ぶ

セッションを教材にする

ツール呼び出し数がしきい値を越えたターンの終わりに、作業の一部を振り返ります。必要なときは /learn で今のセッションから学べます。

ライブラリを保つ

似た技能をまとめる

同じ場面に向けた提案は新規追加だけでなく、既存スキルへの統合や更新として扱います。セッション開始時には管理対象の索引を提示します。

02 / 学習の流れ

記録、提案、検証、再提示を別の責務に分けています。学習処理は通常のセッションに並走します。

01 / CAP

作業を捕捉

フックがターンとツール利用を記録。外へ渡す際に機密情報を伏せ、既存のホストログを参照します。

02 / REF

改善を提案

リフレクターが既存スキルと照合し、追加・統合・更新などの意図を作ります。

03 / PROMOTER

検証して保存

提案の安全性と構造を検査し、通ったものだけをスキルディレクトリへ反映します。

04 / IDX

次回に提示

管理対象スキルをカテゴリ別に並べ、次のセッション開始時に索引として渡します。

05 / MNG

利用状況を評価

読み込み・閲覧・更新を別々に数え、十分な機会を経たスキルだけを整理対象にします。

06 / CURATOR + LED

統合し、履歴を残す

全体の重複を統合。スキルごとの台帳に変更理由と根拠を記録します。

03 / 書き込みの境界

スキル提案をそのままファイル操作に結び付けない設計です。

提案側

Reflector は書き込まない

エピソードから変更意図と根拠を作り、保存は行いません。古いスキルと矛盾する提案では、矛盾の解消も同じ実行内で求められます。

保存側

Promoter が検証する

構造・安全性・台帳・自作スキルかどうかを確認し、合格した変更だけを原子的に配置します。却下理由は実行結果に残ります。

対象の制限: 管理するのは AutoHarness の台帳マーカーを持つ自作スキルだけです。利用者が書いたスキルや別途インストールしたスキルは変更対象にしません。

04 / スキルの寿命

経過時間ではなく、利用機会に対する実際の使われ方を見ます。

段階判定・動作ディスク上の結果
試用期間一定数のリクエストが届くまで評価を待つ。索引には引き続き表示。.claude/skills/<name>/ に保持
卒業判定試用期間中に読み込みも閲覧も一度もなければアーカイブ。.claude/skills/.archive/ へ移動
容量超過成熟したスキルが上限を越えた場合、利用率が低いものから整理。削除せずアーカイブ。戻せば復帰可能

利用率に数えるのはスキルの読み込みです。閲覧は卒業判定の根拠にし、更新は改善後の再利用を見分けるため別に記録します。

05 / 導入と確認

Claude Code のプラグインとして導入します。実行環境には python3 が必要です。

Claude Code の入力欄 
/plugin marketplace add tigerless-labs/autoharness
/plugin install autoharness@autoharness
/reload-plugins

再読み込み後は通常の作業を続けるだけで動きます。学習を明示的に依頼するときは /learn を使います。

動作を確かめる場所: 自作スキルは .claude/skills/、プロジェクトごとの実行記録は .claude/autoharness/ に置かれます。各スキルの .ledger.jsonl に変更理由と根拠が残ります。

06 / 主な設定

環境変数 AUTOHARNESS_* で学習間隔とスキルの上限を調整できます。

変数既定値役割
REFLECT_EVERY_N50振り返りまでのツール呼び出し数
CONSOLIDATE_EVERY_N250ライブラリ全体の統合までのリクエスト数
MATURITY_PROJECT / MATURITY_GLOBAL100 / 300卒業判定までのリクエスト数
CAPACITY_PROJECT / CAPACITY_GLOBAL50 / 20各層で保持する成熟スキルの上限
INDEX_SUSPENDED01 にするとセッション開始時の索引注入を停止

表中の変数名にはすべて AUTOHARNESS_ を付けます。既定値はソース README の値です。
