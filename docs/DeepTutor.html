1 — 概要
What is DeepTutor?

DeepTutor は、個別指導・問題解決・問題作成・調査・可視化・習熟練習を 1 つのシステムにまとめた Agent-Native な学習ワークスペース。Chat や Quiz などのモードは 1 つの Capability ランタイムとセッション文脈を共有し、知識ベース・Book・ノートブック・問題バンク・Memory をモード間で使い回す。バックエンドは FastAPI（Python 3.11〜3.14）、フロントエンドは Next.js 16。

Web・CLI・IM のどこから来たメッセージも、同じ ChatOrchestrator のターンとして処理される。Partner は独立したボットエンジンではなく、Partner 専用のワークスペースで動く通常の Chat ターンである。

2 — Capability（モード）
1 つのランタイムで動く 11 モード

各モードは専用のループやパイプラインを持つが、セッション文脈は共通。Web のホームには Chat / Ask Questions / Quiz / Visualize が並び、Research と Solve は More Capabilities、Book・Mastery Path・Immersive Reading・Practice は Personalized Learning にまとめられている。括弧内は deeptutor run に渡す名前。

モード内容
Chat（chat）既定のモード。ツール呼び出し、知識ベース参照、添付ファイル読解、画像生成、サブエージェント相談、ノート書き込みを 1 スレッドで行う。
Ask Questions（ask_questions）足りない文脈を埋めるため、DeepTutor 側から質問カードで聞き取りを行う。
Solve（deep_solve）途中の推論を示しながら問題を解く。
Quiz（deep_question）問題を生成する。結果は問題バンクに保存でき、Practice で復習に使える。
Research（deep_research）引用付きのレポートを作る。mode や depth を --config で指定する。
Visualize（visualize）図や可視化を生成する。表示形式はプラグインで追加できるカタログ方式。
Math Animator（math_animator）数学の概念を Manim のアニメーションにする。
Mastery Path（mastery_path）習熟度ベースの個別指導。専用の状態機械は持たず、Chat と同じループエンジンを指導用プロンプトで動かす。モードごとに使えるツールが制限される。
Immersive Reading（immersive_reading）文書・動画・音声を横に開いて読み進める。開いている箇所を把握し、ページ単位で引用する。YouTube / Bilibili は字幕検索とタイムスタンプ付きで扱える。
Course Study（course_study）コースに紐づいた文脈で、次に何を学ぶかを決めて他のモードへ引き継ぐ。
Audio Overview（audio_overview）知識ベースの内容から、2 人の話者による音声解説と書き起こしを作る。
3 — Chat の動き方
エージェントループ
flowchart LR T["考える"] --> C{"ツールが必要?"} C -->|はい| R["ツール呼び出し"] --> O["結果を観察"] --> T C -->|確認が必要| A["ask_user で質問
ターンを一時停止"] -->|回答| T C -->|いいえ| F["ツールなしの
メッセージで終了"]

ループは単純な構造で、モデルはラウンドごとに考え、必要ならツールを呼び、結果を見て、ツールを使わないメッセージで締める。ask_user だけは特別で、推測で進めずにターンを止めて構造化された質問を出し、回答後に再開する。

ツールの 2 種類
  • ユーザーが切り替えるツール — brainstorm / web_search / paper_search / zotero_search / reason / geogebra_analysis。生成モデルを設定すると imagegen / videogen も加わる。
  • 文脈で自動的に載るツール — rag、read_memory、exec、web_fetch、ask_user、write_note、question_bank、consult_subagent、workspace_* など。ターンに必要な条件が揃ったときだけ使える。
文脈の 2 種類
  • セッションに残る文脈 — Capability、ワークスペースまたはコース、ツール、知識ベース、ペルソナ、モデル、Reading / Mastery の状態。ターンをまたいで保持される。
  • 1 ターン限りの参照 — ファイル、過去のチャット、Book、読書箇所、ノートブック、問題バンクの項目、取り込んだエージェントの会話。+ メニューから付ける。
4 — 主要な画面
Partners

常駐するコンパニオン。各 Partner は SOUL.md（人格）、モデル、ツール方針、割り当てライブラリ、Memory、チャネルを持つ。旧版の TutorBot に相当する機能だが、別エンジンではなく Partner 用ワークスペースの Chat ターンとして動く。

  • 接続先は Feishu / Telegram / Slack / Discord / DingTalk / QQ / WeCom / WhatsApp / Zulip / Mattermost / Matrix / Microsoft Teams など。
  • Feishu/Lark・WeCom・個人 WeChat はブラウザに表示した QR コードから接続できる。
  • Chat からサブエージェントとして相談することもできる。
My Agents

他のエージェントを DeepTutor の文脈として使う。役割は 2 つ。

  • 稼働中のエージェントに相談 — Claude Code / Codex / Grok CLI / Antigravity / Kimi / opencode / MiMo Code / Hermes Agent / OpenClaw / DeepSeek Harness、または Partner を consult_subagent で実際に実行し、作業内容を Activity パネルに流す。
  • 過去の会話を取り込む — ChatGPT のエクスポート、Claude Code（プロジェクト単位）、Codex（日付単位）の履歴を検索・再開できる会話として取り込む。DeepTutor 自身の発言ではなく第三者の記録として扱う。
Book

選んだ資料から「生きた本」を作る。作成時はまず章立てが提案され、確認してから本文を生成する。

  • 章はテキスト・クイズ・フラッシュカード・年表・コード・図・インタラクティブ HTML・概念グラフなどの型付きブロックで構成され、ブロック単位で挿入・移動・再生成できる。
  • 章ごとに Page Chat を持つ。進捗・ブックマーク・回答履歴は共有された本でも読者ごとに分かれる。
  • Markdown へ書き出せる。
Co-Writer

左右分割の Markdown エディタ。自動保存とライブプレビュー（KaTeX、図）を備え、.docx の読み込みと Markdown / Word の書き出しに対応する。

範囲を選んで書き換え・展開・短縮を指示する部分編集が中心。知識ベースや Web の根拠を使え、作業中に原稿が変わっていなければ選択範囲を直接置き換える。Undo で戻せる。

Learning Space
  • Conversations & Materials — チャット履歴、ノートブック、解答と解説付きの問題バンク。
  • Practice — 問題バンクから復習セッションを始め、間違いの記録と間隔反復を行う。
  • Personalization — ペルソナ、Skills（SKILL.md）、MCP Services、CLI-Anything カタログの CLI Apps。
Task Board と Settings
  • Task Board — 学習タスクを To do / In progress / Done で管理する。ドラッグかキーボード操作で移動でき、アーカイブから復元できる。モデル設定は不要。
  • Settings — 検索できるナビゲーターから各ページへ移動する。多くの項目は下書きして接続テストしてから適用する。Chat で「設定を変えて」と頼むこともでき、API キーはモデルに渡さず該当フォームを開く。
5 — Knowledge Center
知識ベースごとにエンジンを選ぶ

知識ベースは Chat・Co-Writer・Book・Partner の根拠になる文書の集まり。1 つの知識ベースは 1 つのエンジンに紐づく。

エンジン検索方式・用途
LlamaIndex（既定）ベクトル + BM25 のハイブリッド。cross-encoder による再ランクと FAISS（exact-flat / HNSW）を選べる。
PageIndex推論による検索とページ単位の引用。ホスト版とセルフホスト OSS 版。
GraphRAG / LightRAG知識グラフによる検索。LightRAG は deeptutor[rag-lightrag] で導入する。
LightRAG Server外部の LightRAG インスタンスへ HTTP で検索を任せる。
WeKnoraセルフホストの WeKnora から検索する。ローカルの索引や文書コピーを持たない。
Tencent IMAIMA で管理するライブラリを OpenAPI 経由で検索・閲覧・書き込みする。
MarginNote 4MN4 の文書・抜粋・マインドマップカードを Add-on から送り込み、専用ツールで辿る。
KiwixHTTP で配信される ZIM アーカイブを索引なしで検索する。
Obsidianリンクした Vault をその場で読み書きする。
作成と同期
  • 作成方法は 新規作成（アップロードして索引化）、既存の索引をリンク、Kiwix に接続 の 3 つ。
  • GitHub リポジトリ（リポジトリ・ブランチ・glob）やドキュメントサイトの URL を追跡できる。既定では 24 時間ごとに再同期し、差分だけを反映する。
  • LightRAG の索引は作成時の埋め込み設定を記録する。設定を変えた場合は元に戻すか再構築する。
検索品質の採点

どのエンジンがよいかは deeptutor kb eval で実測する。query と理想の検索結果 gold を 1 行ずつ書いた QA セットを用意し、Chat と同じ経路で検索した結果を照合する。

{"query": "Why do transformers scale attention?", "gold": ["Scaling keeps the dot products from growing with the dimension."]}

deeptutor kb eval textbook --dataset qa.jsonl --top-k 5 --save baseline.json
6 — Memory と Content Workspace
3 層の Memory

Memory は隠れたベクトルストアではなく、読んで編集・監査できるファイルで構成される。Memory Graph では L3 を中心に、L2 → L1 の根拠リンクと L3 → 元の L2 のリンクを確認できる。

層保存場所内容
L1trace/<surface>/<date>.jsonlワークスペースのミラーと追記専用のイベント記録
L2L2/<surface>.md画面（chat / notebook / quiz / kb / book / partner / cowriter）ごとに整理した事実。L1 の項目を参照する
L3L3/<profile|recent|scope|preferences>.md画面を横断した統合。どの L2 から作ったかを記録する
Content Workspace

エージェントが読めるフォルダで、設定や認証情報を置く private runtime home とは別に管理される。生成物は outputs/<capability>/<session>/<turn>/ に出力される。

  • モデルが受け取るのは outputs/... のような相対パスだけ。
  • outputs/ の外は読み取り専用。生成物を他の場所へコピーするには、コピー元と先を指定した Allow once の確認が要る。
  • この境界はシステムのサンドボックスか Docker runner が強制する。どちらも使えない環境では best effort と表示される。
deeptutor workspace show
deeptutor workspace set /absolute/path/to/my-folder
deeptutor workspace reset
7 — DeepTutor CLI
人が使う REPL、エージェントが使う NDJSON

deeptutor コマンド 1 つで、対話型 REPL と構造化 JSON の両方を提供する。--format json を付けると、各ターンが 1 行 1 イベントの NDJSON（content / tool_call / tool_result / done …）で流れ、すべての行に session_id が付く。TTY がない場合、ask_user は空の回答で自動的に進むため止まらない。

# 対話型
deeptutor chat --capability deep_solve --kb my-kb --tool rag

# 1 回だけ実行
deeptutor run chat "Explain the Fourier transform" --tool rag --kb textbook

# セッションをつないで連続実行（エージェント向け）
SID=$(deeptutor run deep_research "Survey 2026 papers on RAG" \
  --config mode=report --config depth=standard --format json \
  | jq -r 'select(.type=="done").session_id')
deeptutor run deep_question "Quiz me on that survey" --session "$SID" --format json

リポジトリ直下の SKILL.md は CLI の引き継ぎ用ドキュメント。エージェントに読ませると DeepTutor を CLI で操作できる。

コマンド用途
deeptutor initセットアップウィザード（ポート → LLM → 埋め込み → 検索）。--non-interactive で既定値だけ作る
deeptutor doctor [--online]起動できる状態か診断する。--online でモデルプロバイダーにも接続確認する
deeptutor start / stop / serveバックエンドとフロントエンドを起動・停止する。serve は FastAPI だけ
deeptutor run <capability> <message>任意の Capability を 1 ターン実行する
deeptutor kb知識ベースの作成・追加・検索・採点（eval / eval-diff）・ソース同期
deeptutor partnerIM 接続の Partner を一覧・作成・起動・停止する
deeptutor skillSkills の検索・インストール・公開
deeptutor memory / session / notebook / bookMemory、セッション、ノートブック、Book の参照と管理
deeptutor pluginツールと Capability の確認、審査済みプラグインの導入・承認・ロールバック
deeptutor config解決済み設定の表示（認証情報は伏せ字）、設定 JSON の適用と検証
deeptutor provider login <provider>openai-codex の OAuth、github-copilot のデバイスログインなど
8 — EduHub と Skills
Agent-Skills 形式のスキル

DeepTutor のスキルは、SKILL.md（YAML frontmatter + Markdown）と参照ファイルを入れたフォルダ。既定の取得元は教育向けレジストリの EduHub で、ClawHub も組み込まれている。

deeptutor skill search "socratic tutor"
deeptutor skill install socratic-tutor
deeptutor skill install eduhub:socratic-tutor@1.2.0
deeptutor skill install clawhub:git-release-notes@1.0.1
deeptutor skill publish ./my-skill
取り込み時の安全チェック

取得元に関係なく、すべての取り込みが同じチェックを通る。

  1. レジストリのセキュリティ判定を確認し、警告付きのパッケージは --allow-unverified なしでは拒否する。
  2. アーカイブはパストラバーサル・件数・サイズ・圧縮率・拡張子・シンボリックリンクを検査して展開し、実行ビットを外す。
  3. frontmatter を正規化し、always: を削除する。取り込んだスキルが全システムプロンプトに常駐することはない。
  4. 取得元・バージョン・判定・導入日時を .hub-lock.json に記録する。
9 — セットアップ
設定の置き場所

旧版の .env による設定は廃止された。プロジェクト直下の .env は意図的に無視され、設定は起動ディレクトリ配下の data/user/settings/*.json（または DEEPTUTOR_HOME / deeptutor start --home で指定した場所）に保存される。モデルやプロバイダーは deeptutor init か Web の Settings → Providers で設定する。

試すだけ
Docker 1 コマンド
docker run --rm -p 127.0.0.1:3782:3782 -v deeptutor-data:/app/data ghcr.io/hkuds/deeptutor:latest で起動し、http://127.0.0.1:3782 を開く。設定は名前付きボリュームに残る。
Option 1
PyPI からインストール
Web アプリと CLI の両方が入る。Python 3.11〜3.14 と Node.js 20 以上が必要。pip install -U deeptutor → deeptutor init → deeptutor start。
Option 2
ソースからインストール
開発向け。CI と同じ Python 3.11〜3.14 と Node.js 22 LTS を使う。RAG エンジンや Partner 用のチャネルは extras で追加する。
Option 3 / 4
Docker / CLI のみ
Docker は 1 つのコンテナで完結する構成と Compose 構成がある。Web UI が不要なら pip install -e ./packaging/deeptutor-cli（PyPI 未公開のためソースから）。
エージェントにセットアップを任せる

README には、Codex や Claude Code などに渡すためのプロンプトが用意されている。エージェントは SKILL.md と docs-for-user/AGENT_SETUP.md を読み、環境準備・プロバイダー設定・動作確認・起動まで進める。API キーは表示しないよう指示されている。

Help me install and configure DeepTutor locally from https://github.com/HKUDS/DeepTutor.
Clone the repository, or reuse my existing checkout, and read SKILL.md and
docs-for-user/AGENT_SETUP.md first. Follow that guide to prepare the environment,
configure my model provider, verify the setup, and start the Web app.
Ask me for any missing provider, model, or credential-source information;
do not print API keys. Preserve my existing files and settings, and finish
with the access URL and the results of your checks.

マルチユーザー

認証は既定で無効（シングルユーザー）。data/user/settings/auth.json で有効にすると、最初に登録したユーザーが管理者になり、ユーザーごとに分離されたワークスペースを持つ。

管理者はモデル・知識ベース・Skills・Partner・コード実行の権限をユーザーに付与する。一般ユーザーに API キーそのものは渡らない。Learner アカウントと保護者による承認・レポート機能もある。
