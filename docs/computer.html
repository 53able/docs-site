Cloudflare Computer

Durable Object の SQLite にファイルを保存し、同じ Workspace を 3 種類の実行環境から扱う。

1 — 概要
1 つの永続状態、選べる実行環境

Cloudflare Computer は、Durable Object 内の SQLite を正とする仮想ファイルシステムです。workspace.fs が永続ファイルを操作し、workspace.runtime.exec() が登録済みバックエンドへ処理を振り分けます。ファイルだけを使う構成では、実行バックエンドを登録しなくても構いません。

2 — 全体構成
Durable Object

Workspace.fs → DOFS → SQLite

読み書き、ディレクトリ操作、検索、マウントを Durable Object のストレージ上で処理します。この SQLite 状態が Workspace の正です。

同じ Workspace を実行へ渡す
Runtime router

workspace.runtime.exec(source, { backend })

安定した ID でバックエンドを選びます。接続は初回利用時に作られ、コマンド型とモジュール型の違いは Runtime が吸収します。

用途に応じて 3 経路へ

Container

computerd が FUSE で /workspace をマウント。Linux バイナリとネットワークを使えます。

Isolate shell

just-bash を Dynamic Worker で実行。HOST proxy を通じて同じ SQLite を直接扱います。

Isolate JavaScript

新しい Dynamic Worker で ES module を評価。構造化入力と node:fs/promises を利用できます。

4 — 公開 API
最小構成

withWorkspace で Durable Object に Workspace を組み込み、呼び出し側では getWorkspace() からファイル API を使います。Worker では nodejs_compat が必要です。

TypeScript
import { getWorkspace, withWorkspace } from "@cloudflare/computer";
import { DurableObject } from "cloudflare:workers";

export class Agent extends withWorkspace(
  class extends DurableObject<Env> {},
) {}

export default {
  async fetch(_request, env) {
    const id = env.Agent.idFromName("demo");
    using ws = await getWorkspace(env.Agent.get(id));

    await ws.fs.writeFile("/notes.txt", "durable\n");
    return new Response(await ws.fs.readFile("/notes.txt", "utf8"));
  },
};
実行を追加する

Workspace に backend を登録すると、同じ runtime.exec() から選択できます。最初の backend が既定値になり、{ backend: "stable-id" } で明示的に切り替えられます。

Runtime call
const run = await ws.runtime.exec("cat /workspace/notes.txt", {
  backend: "container",
  encoding: "utf8",
});

const { stdout, exitCode } = await run.result();
5 — パッケージ
@cloudflare/computer

利用者向け facade

Workspace、fs、runtime、各 backend、git、assets、artifacts、AI SDK tools を公開します。

@cloudflare/dofs

SQLite ファイルシステム

スキーマ、ファイル操作、同期部品、computerd が利用する VFS provider を担います。

@cloudflare/computer-rpc

capnweb 契約

Durable Object と computerd の wire types、server / client、同期 driver を共有します。

@cloudflare/computerd

Container 内 daemon

FUSE mount、HTTP / WebSocket RPC、shell 実行を提供し、Container 内の状態を Workspace と同期します。

examples

実際の利用経路

Container、worker-shell、worker-javascript、agent、tutorial、assets の構成例を収録します。

filesystem only

backend は省略可能

実行が不要なら、永続ファイルシステムだけの Workspace として構築できます。

6 — 制約・参照
Preview: API は不安定で、実験・探索・prototype 向けです。現時点では production 用途を想定していません。リポジトリの docs/ は将来仕様であり、現在の main の実装説明とは区別してください。
現在の上限
  • 容量は Durable Object ストレージと共有し、目安は約 10 GB です。
  • Container 側のファイルシステムはメモリ上にあり、大規模ツリーには向きません。
  • FUSE は metadata-heavy な処理に強い一方、大きな連続 I/O や大規模な package install には負荷があります。
  • R2 mount は読み取り専用です。書き込みは EROFS になります。
  • Isolate shell は完全な Linux userland ではありません。JavaScript backend も外向き通信を既定で持ちません。
