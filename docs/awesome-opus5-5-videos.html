awesome-opus5-5-videos

Opus 5.5 でコードから作った動画とプロンプトの一覧 · yihui-dev · MIT

1 — 概要

1 エントリに、動画の元投稿とプロンプトを 1 件ずつ

awesome-opus5-5-videos は、Claude Opus 5.5 にアニメーションをコード（HTML、Canvas、SVG、Three.js など）で書かせて作られた動画を集めたリストです。X（旧 Twitter）で話題になった投稿を対象に、作者が公開したプロンプトを 1 件ずつ Markdown と JSON で収録しています。

動画ファイル自体はリポジトリに含まれません。各エントリは作者の元投稿へリンクし、一部はコンパニオンサイト Skillry 上の再現版（live remake）へリンクします。プロンプトをコピーして、自分のエージェントで同じ種類の動画を作る用途を想定しています。

3 — ファイル構成

ソースコードやビルド手順はなく、Markdown と JSON だけで構成されています。同じエントリが prompts/ と data/videos.json の両方にあり、前者は人が読む用、後者は機械処理用です。

awesome-opus5-5-videos/ ├── README.md # ギャラリー（再現版 100 件の抜粋 + 最新プロンプト 30 件） ├── prompts/ │ └── <作者>-<投稿 ID 末尾 6 桁>.md # 703 ファイル。作者名は小文字化し _ を - に置換 ├── data/ │ └── videos.json # 全 703 件の配列（約 0.8 MB） └── LICENSE # MIT

README のギャラリー

README は全件ではなく、再現版から 1 プロンプト 1 件ずつ選んだ 100 件をカテゴリ別の表で示します（Motion graphics 58、Explainers 16、3D scenes 14、Games & interactive 12）。末尾の Latest prompts には、再現版のない新しいプロンプト 30 件が並びます。全件を見るには prompts/ か videos.json を使います。

prompts/*.md の書式

再現版ありのエントリは、見出し、Skillry と元投稿へのリンク、カテゴリ・技術タグ・作者の箇条書き、## Prompt 以下のコードブロックという並びです。作者がプロンプトの一部しか公開していない場合は、## Prompt の前に注記が入ります。

# Opus 5.5 video by @gautam_mer1

[▶ Watch the original and a live remake on Skillry](…) · [Original post](…)

- **Category:** Motion graphics
- **Remake built with:** Canvas · SVG · GSAP
- **Author:** [@gautam_mer1](https://x.com/gautam_mer1)

> The author shared only part of the prompt.

## Prompt

```text
an Apple-style 30s video of my app
```

再現版のないエントリは title を見出しにし、冒頭のリンクは元投稿だけです。箇条書きはカテゴリと作者のみで、Skillry へは一覧ページへの汎用リンクが 1 行入ります。

4 — videos.json の項目

トップレベルはオブジェクトの配列です。各要素は次の項目を持ちます。

項目型内容
slugstringエントリの ID。prompts/<slug>.md のファイル名と一致
titlestring作品名。再現版のない 285 件にだけある
author / author_urlstringX のハンドルとプロフィール URL
post_urlstring動画を含む元投稿の URL
categorystringmotion / 3d / explainer / interactive
tech_tagsstring[]再現版の技術。再現版がなければ空配列
promptstringプロンプト本文。空のエントリはない
prompt_partialboolean作者がプロンプトの一部だけを公開した場合 true
poster_urlstringSkillry がホストするポスター画像。全件に値がある
skillry_urlstringSkillry の個別ページ。再現版がなければ null
addedstring収録日（YYYY-MM-DD）
has_remakebooleanSkillry に再現版があるか
再現版の有無で性質が違います。 prompt_partial: true の 207 件はすべて再現版ありのエントリです。再現版なしの 285 件は 2026-10-12 に追加された分で、全件がプロンプト全文です。

7 — プロンプトを試す

README が示す手順は次の 3 つです。

  1. prompts/ のファイルを開き、Prompt 以下のブロックをコピーする。
  2. Claude Opus 5.5 を使う環境（Claude Code、Claude アプリ、Opus 5.5 で動く任意のエージェント）に貼り付ける。
  3. 結果を 1 つの HTML ファイルとして出力させ、動画が必要ならページを録画する。

条件で絞り込むときは videos.json を使います。次の例はリポジトリを取得し、再現版があってプロンプト全文が公開されている 3D エントリを数え、1 件の本文を取り出します。

git clone https://github.com/yihui-dev/awesome-opus5-5-videos.git
cd awesome-opus5-5-videos

# 再現版あり・全文公開の 3D エントリ数（92aee2f 時点で 18）
jq '[.[] | select(.category == "3d" and .has_remake and (.prompt_partial | not))] | length' data/videos.json

# slug を指定してプロンプト本文だけを出力
jq -r '.[] | select(.slug == "emollick-019567") | .prompt' data/videos.json

再現版のある 418 件は、skillry_url のページで元動画と再現版を並べて確認できます。再現版のないエントリでは、post_url の元投稿を見てください。

8 — 利用時の注意

  • 権利の扱い: LICENSE は MIT ですが、README の Credits では各動画とプロンプトは作者に帰属すると明記しています。プロンプトや動画を転載・再配布する場合は、元投稿の作者の扱いを確認してください。
  • 再現できないプロンプトがある: 207 件は一部だけの公開です。全文のものでも、作者のローカルフォルダ、独自スキル、外部 API キー（音声生成・画像生成など）を前提にした指示を含む場合があり、そのままでは同じ結果になりません。
  • 技術タグは元動画の情報ではない: tech_tags は Skillry の再現版の実装を示します。元の作者が使った技術とは一致しない場合があります。タグ名から見て、ai-image の 6 件は再現版に AI 生成画像を使っていると考えられます。
  • 外部サービスへの依存: 動画の視聴は X と Skillry に依存します。投稿の削除やサイトの変更でリンクが切れても、リポジトリ側では検知されません。README と prompts/*.md の Skillry へのリンクには UTM パラメータが付いています（videos.json の skillry_url には付いていません）。
  • モデルの出力は毎回変わる: 同じプロンプトでも生成結果は一定ではありません。紹介されている動画は、作者が選んだ結果、または手を加えた結果である可能性があります。
